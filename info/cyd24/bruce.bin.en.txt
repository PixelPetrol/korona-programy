Bruce - a multi-protocol security testing toolkit (WiFi, BLE, IR, RF), LITE variant. A third-party program, built for the CYD 2.4" with corrected colours.
Status: the store description has no record of this binary being tested on a board.
Needs: nothing but the board; you add IR and RF modules yourself. The first start asks for a four-corner touch calibration (landscape); after changing Config > Orientation Bruce asks once for the new layout and remembers it (K-OS keeps it in the snapshot).
Limits: use it only on your own networks and devices.
Author: pr3y (the Bruce project). Image prepared for K-OS: RST returns to the menu.
