BETA - not yet run on a board. The board becomes a wireless keyboard, mouse and remote over Bluetooth LE (one HID device, no drivers or apps) for a Windows computer, an Android phone, iPhone and iPad, and a Google TV. Modes: touchpad (portrait like the rest of the program, tap = click, hold = drag, scroll strip), on-screen keyboard (QWERTY, ?123 page, accented letters per host layout), TV remote (d-pad with OK, back, home, volume, playback) and a 3x4 shortcut grid with profiles on the card (/control/profile/*.txt) - starting with Windows Desktop, Zoom, Teams, OBS, PowerPoint and YouTube on TV. You edit shortcuts from your phone: the 'From phone' screen joins the WiFi saved in K-OS and shows a QR code and a 4-digit session code; on a computer the page records combinations from the real keyboard. A simple tile editor is on the board too. Up to 4 paired devices, one connected at a time. Pairing only on the 'Pairing' screen (60 s) with confirmation on the board. After a restart the board reconnects to the last device by itself; nothing is typed on its own, and the Bluetooth state and the name of the device receiving the key presses are always on screen. Risky tiles (Win+R, Win+L, Ctrl+Alt+Del) need a 1 s hold. The web page runs only on that screen, 5 wrong codes stop the server; it is plain http in your home network, not encrypted. THE SD CARD IS A KEY: the K-OS snapshot on the card holds the pairing keys - whoever copies it can pose as your keyboard; 'forget all' draws a new Bluetooth address. A remote and keyboard for your own devices; not for typing on other people's computers. The 'text' and 'macro' tiles and the 'Type text' page tab type to the host with a TYPING bar and STOP; the profile is picked automatically for the connected host. Not there yet: air mouse (needs an add-on IMU module). Limits: the board sends key codes, not letters - typing uses the host layout (US / PL programmers / macOS Polish Pro / no accents), set per device; the touchpad takes one finger; on iPhone the mouse works only with AssistiveTouch; without an SD card pairing is not remembered. Diagnostics: hold the Settings title for 2 s (probe: Bluetooth and memory state). 2.4" version (ESP32-2432S024R).
