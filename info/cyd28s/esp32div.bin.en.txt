A version for the CYD 2.8" with an ST7789 panel (the board with two USB sockets). Hardware-identical to the ordinary 2.8" model - the same screen pins, the same XPT2046 touch, backlight GPIO 21 - it differs only in the display driver. The author has no ready profile for the ST7789 (he has only ILI9341 and ST7796), so the profile was added here. The image contains the return-to-K-OS patch: a reset goes back to the system. NOT TESTED ON HARDWARE - if the colours come out like a negative or with red and blue swapped, those are one-flag fixes. Touch and the buttons should work unchanged, because the controller and the pins are the same as in the tested 2.8" version.
