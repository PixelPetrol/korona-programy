Bruce for the CYD 2.8" in the two USB socket revision - the same board as cyd28, but with an ST7789 panel. The screen, touch, backlight and SD card pins are identical; only the display controller changed, so the image is produced from the same code and differs in the driver, the BGR colour order and the inversion setting. The settings were derived FROM THE CODE of the library and from the canonical configuration of this board, not from a check on hardware. If anything is to come out wrong, it will be the colours (a negative or red swapped with blue) or an image rotated by 180 degrees relative to cyd28 - and with a rotated image the touch hits mirrored places. Return to K-OS with the RST button works as in the other images. NOT TESTED ON HARDWARE.
