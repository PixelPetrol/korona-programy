The same game as on the 2.8" (0.3.0 BETA: upgrade cards during the run), built for the revision with the ST7789 screen driver (the board with TWO USB sockets). The XPT2046 touch, bit-banged on the board's own pins (CLK 25, MOSI 32, MISO 39, CS 33, IRQ 36), and the GPIO 21 backlight are the same as on cyd28 - only the screen driver differs; it is compiled into the library, hence a separate image. Touch calibration comes from K-OS (/korona/cyd28s/dotyk.txt); without it a default is used and the serial port says so. The same game image, the same saved state. NEVER RUN ON THIS BOARD. If the image comes out as a negative or with red and blue swapped - write in, the fix is one flag.
