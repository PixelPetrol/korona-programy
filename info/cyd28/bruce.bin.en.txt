A version for the CYD 2.8" (2432S028R) from the KORONA_CYD28 environment, built from the author's native profile `CYD-2432S028` - touch on dedicated pins, without our patch for the 2.4". Colours without inversion, because the base for this board does not define TFT_INVERSION_ON. Return to K-OS after RST is assured. NOT TESTED ON HARDWARE. Known risk: the default touch rotation correction in InputHandler adds up with the driver's internal rotation - this is upstream code used by the community on real 2.8" boards, but we have not confirmed it.
