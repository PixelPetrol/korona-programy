Portal jest statyczny — nie ma tu czego przyjąć pliku. Dlatego sprawdzanie dzieje się u Ciebie: FileReader czyta plik z dysku, crypto.subtle liczy sumę. Żaden bajt nie wychodzi poza tę kartę przeglądarki. Sam plik .bin dołączysz na końcu na GitHubie — tam, gdzie i tak trafiają zgłoszenia. This portal is static — there is nothing here to receive a file. So the checking happens on your side: FileReader reads the file from disk, crypto.subtle computes the hash. Not a byte leaves this browser tab. You attach the .bin itself at the end, on GitHub — where submissions go anyway.

co dokładnie jest sprawdzanewhat exactly gets checked
  • magic 0xE9 na bajcie 0 — czysty obraz aplikacji ESP32.Magic 0xE9 at byte 0 — a plain ESP32 application image.
  • obraz scalony: 0xE9 pod 0x1000 plus tablica partycji AA 50 pod 0x8000 — wtedy oceniana jest aplikacja wycięta spod 0x10000.Merged image: 0xE9 at 0x1000 plus an AA 50 partition table at 0x8000 — then the application carved out at 0x10000 is what gets judged.
  • długość obrazu z nagłówka (segmenty + suma kontrolna + opcjonalny SHA-256), nie z rozmiaru pliku — dlatego wycinek ze scalonego obrazu jest bajt w bajt tym, co wyszło z kompilatora.Image length from the header (segments + checksum + optional SHA-256), not from the file size — that is why the extract from a merged image is byte for byte what the compiler produced.
  • esp_app_desc_t spod 0x20 (magic_word == 0xABCD5432): project_name, version, idf_ver, data i godzina kompilacji.esp_app_desc_t at 0x20 (magic_word == 0xABCD5432): project_name, version, idf_ver, build date and time.
  • układ z nagłówka: musi być zwykły ESP32, nie S2/S3/C3.Chip from the header: must be a plain ESP32, not an S2/S3/C3.
  • rozmiar wobec slotu ota_0 = 2 555 904 B, z zapasem w bajtach.Size against the ota_0 slot = 2,555,904 B, with the headroom in bytes.
  • sha256 pliku i obrazu (i zgodność SHA-256 doklejonego do obrazu) — ten sam numer, który policzy automat w PR.sha256 of the file and of the image (and whether the SHA-256 appended to the image matches) — the same number the PR automation computes.

2. Opis programu2. Describing the programz tego powstaje meta.jsonthis becomes meta.json

2–32 znaki: małe litery a-z, cyfry, -, _. To zostaje na zawsze — id jest nazwą pliku w sklepie i kluczem migawki ustawień na karcie, więc po publikacji nie da się go zmienić bez utraty ustawień użytkowników. 2–32 chars: lowercase a-z, digits, -, _. This is permanent — the id is the store file name and the key of the settings snapshot on the card, so after publication it cannot change without losing users’ settings.
