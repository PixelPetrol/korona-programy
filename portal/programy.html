1. Co to znaczy „program pod KORONĘ"1. What “a KORONA app” means

  • Czysty obraz aplikacji ESP32. To, co Arduino / PlatformIO zapisuje jako *.ino.bin / firmware.bin: bajt 0 = 0xE9. Bez bootloadera, bez tablicy partycji, nie plik „merged" (ten automat sklepu rozpozna i wytnie z niego aplikację, ale na kartę SD wrzucaj czysty).A plain ESP32 application image. What Arduino / PlatformIO writes as *.ino.bin / firmware.bin: byte 0 = 0xE9. No bootloader, no partition table, not a “merged” file (the store automation recognises and extracts the app from a merged file, but put a plain image on the SD card).
  • Slot ota_0 = 2 555 904 B (0x270000) pod adresem 0x170000. KORONA kopiuje tam Twój .bin z karty i uruchamia go. Obraz ESP32 nie jest przywiązany do adresu, więc kompilujesz normalnie.Slot ota_0 = 2 555 904 B (0x270000) at address 0x170000. KORONA copies your .bin from the card into it and boots it. An ESP32 image is not tied to an address, so you build normally.
  • Tablica partycji ładowarki. Twoja własna tablica (schemat z Arduino, partitions.csv z PlatformIO) jest IGNOROWANA — program widzi nvs 20 KB, spiffs 112 KB i tyle.The loader’s partition table. Your own table (Arduino partition scheme, PlatformIO partitions.csv) is IGNORED — the program sees nvs 20 KB, spiffs 112 KB and that is all.
  • Migawki ustawień. Przed startem KORONA przywraca nvs+spiffs Twojego programu z karty, a po powrocie do menu je zapisuje. Każdy program ma własne ustawienia, WiFi zapamiętane raz zostaje. Klucz migawki = nazwa pliku .bin.Settings snapshots. Before starting, KORONA restores your program’s nvs+spiffs from the card, and saves them when you return to the menu. Each program keeps its own settings; WiFi saved once stays saved. The snapshot key is the .bin file name.

2. Model B — reset wraca do menu2. Model B — reset returns to the menujedyny twardy wymógthe one hard requirement

Bez tego reset nie wraca do menu i płytkę odzyskasz tylko po USB. Bootloader ESP32 wybiera partycję po otadata; KORONA ustawia tam „uruchom ota_0". Twój program musi to skasować na samym początku — wtedy następny RST trafia do factory, czyli do menu. Without this, reset does not return to the menu and the board is recoverable only over USB. The ESP32 bootloader picks the partition from otadata; KORONA writes “boot ota_0” there. Your program must erase it right at the start — then the next RST lands in factory, i.e. the menu.

Wklej na początek setup() (Arduino i ESP-IDF, każdy rdzeń):Paste at the top of setup() (Arduino and ESP-IDF, any core):

#include <esp_partition.h>

void setup() {
  // KORONA "Model B": kasuj otadata -> kazdy RST wraca do menu
  const esp_partition_t* od = esp_partition_find_first(
      ESP_PARTITION_TYPE_DATA, ESP_PARTITION_SUBTYPE_DATA_OTA, NULL);
  if (od) esp_partition_erase_range(od, 0, od->size);

  // ... reszta setup()
}
Alternatywa (tylko rdzeń Arduino): verifyRollbackLater()Alternative (Arduino core only): verifyRollbackLater()

Rdzenie Arduino 2.0.x i 3.x mają CONFIG_APP_ROLLBACK_ENABLE, a bootloader KORONY ma CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y. Obraz uruchomiony po raz pierwszy jest w stanie „do potwierdzenia" — jeśli go nie potwierdzisz, bootloader przy resecie sam wraca do factory. Wystarczy jedna linia na poziomie pliku i nie wołać esp_ota_mark_app_valid_cancel_rollback():Arduino cores 2.0.x and 3.x have CONFIG_APP_ROLLBACK_ENABLE, and KORONA’s bootloader has CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y. An image booted for the first time is “pending verification” — if you never confirm it, the bootloader falls back to factory on reset by itself. One file-level line, and do not call esp_ota_mark_app_valid_cancel_rollback():

bool verifyRollbackLater() { return true; }

Dlaczego to jest potrzebne: rdzeń Arduino w initArduino() (esp32-hal-misc.c) sam potwierdza obraz, chyba że verifyRollbackLater() zwróci true. Zmierzone 03.09.2026 na rdzeniach 2.0.17 i 3.3.11.Why this is needed: the Arduino core confirms the image itself in initArduino() (esp32-hal-misc.c) unless verifyRollbackLater() returns true. Measured 2026-09-03 on cores 2.0.17 and 3.3.11.

Model B jest pewniejszy (działa też w ESP-IDF i gdy ktoś zbuduje bootloader bez rollbacku) — jeśli możesz, użyj Modelu B.Model B is the safer choice (works in ESP-IDF too, and with a bootloader built without rollback) — use Model B if you can.

Program sam robi ESP.restart() (np. po zapisie WiFi)?Does your program call ESP.restart() (e.g. after saving WiFi)?

Po restarcie wraca menu KORONY — to zamierzone. Użytkownik uruchamia program ponownie (albo robi to autostart), ustawienia zostają dzięki migawce. Napisz o tym w polu info zgłoszenia, jak robią to NerdMiner i Pogoda w sklepie.After the restart the KORONA menu comes back — by design. The user starts the program again (or autostart does), settings survive thanks to the snapshot. Mention it in the info field of your submission, as NerdMiner and Pogoda do in the store.

4. Dotyk4. Touch

  • Kalibruj w tej rotacji, w której rysujesz. getTouch() bierze granice z kalibracji, a wymiary z bieżącej rotacji — kalibracja z poziomu użyta w pionie daje rozciągnięcie, nie obrót. Bez „poprawek" współrzędnych. Program, który zmienia orientację w locie, trzyma osobną kalibrację na każdą (tak robi Bruce w sklepie).Calibrate in the rotation you draw in. getTouch() takes the bounds from the calibration but the dimensions from the current rotation — a landscape calibration used in portrait stretches instead of rotating. No coordinate “fix-ups”. A program that switches orientation at runtime keeps a separate calibration per orientation (that is what Bruce in the store does).
  • WDT. tft.calibrateTouch() kręci while(!validTouch()) bez yield() — po kilku sekundach bez dotyku watchdog resetuje płytkę. Owiń kalibrację w disableCore0WDT()/disableCore1WDT() … enableCore*WDT().WDT. tft.calibrateTouch() spins in while(!validTouch()) without yield() — a few seconds without a touch and the watchdog resets the board. Wrap the calibration in disableCore0WDT()/disableCore1WDT() … enableCore*WDT().
  • Wygaszacz. Jeśli masz własny wygaszacz ekranu / timer podświetlenia, wyłącz go na czas kalibracji — użytkownik czeka na róg, ekran gaśnie, kalibracja idzie w ciemno.Screensaver. If you have your own screensaver / backlight timer, disable it during calibration — the user waits for a corner, the screen goes dark, the calibration proceeds blind.
uint16_t cal[5];
// znana dobra kalibracja pionu (setRotation(0)) na S024R - jako start, gdy nic nie zapisano
static const uint16_t CAL_PION_S024R[5] = { 425, 3360, 392, 3504, 3 };

void kalibruj() {
  disableCore0WDT(); disableCore1WDT();
  wygaszaczStop();                       // wlasny wygaszacz, jesli masz
  tft.setRotation(0);                    // TA SAMA rotacja, w ktorej rysujesz
  tft.fillScreen(TFT_BLACK);
  tft.calibrateTouch(cal, TFT_GREEN, TFT_BLACK, 15);
  enableCore0WDT(); enableCore1WDT();
  zapiszDoNVS(cal);                      // Preferences / NVS - przetrwa dzieki migawce
  tft.setTouch(cal);
}

9. Czego NIE da się zrobić z gotowym obcym .bin9. What you can NOT do with a ready-made third-party .bin

Obcej binarki bez źródła nie da się zawrócić do menu. Format tak — automat wycina aplikację ze scalonego obrazu, sprawdza rozmiar, liczy sumy. Ale powrót po resecie to kod, który musi być w programie. Zmierzone 03.09.2026: bootloader KORONY ma rollback, więc niepotwierdzony obraz wróciłby do factory — tylko że rdzeń Arduino (2.0.17 i 3.3.11) potwierdza obraz sam w initArduino(), zanim wykona się choć jedna linia setup(). Każda binarka Arduino zatwierdza się więc sama i pętla wraca do niej. Bez źródła nie ma czego zmienić. A third-party binary without source cannot be made to return to the menu. The format, yes — the automation extracts the app from a merged image, checks the size, computes hashes. But returning on reset is code that has to live inside the program. Measured 2026-09-03: KORONA’s bootloader has rollback enabled, so an unconfirmed image would fall back to factory — except the Arduino core (2.0.17 and 3.3.11) confirms the image itself in initArduino(), before a single line of setup() runs. Every Arduino binary therefore confirms itself and the loop comes back to it. Without source there is nothing to change.
