K-OS — KORONA OS for CYD. Menu programów dla płytek ESP32 „Cheap Yellow Display". K-OS — KORONA OS for CYD. A program menu for ESP32 “Cheap Yellow Display” boards.

Programy na karcie microSD. Dotykasz — startuje. Reset — wracasz do menu. Apps live on a microSD card. Tap — it runs. Reset — you are back in the menu.

K-OS 0.3.9

Piszesz własny program? → jak przygotować go pod K-OSWriting your own app? → how to make it K-OS-ready

Najpierw: kopia zapasowa płytkiFirst: back up the board zrzut całego flasha do pliku, zanim wgrasz K-OSdump the whole flash to a file before installing K-OS

Wgranie K-OS nadpisuje bootloader, tablicę partycji i program, który dziś siedzi na płytce. Ta kopia czyta cały flash (zwykle 4 MB) przez USB i oddaje jeden plik .bin. Z niego da się wrócić do stanu sprzed instalacji — jedną komendą albo przyciskiem niżej. Installing K-OS overwrites the bootloader, the partition table and whatever program lives on the board today. This backup reads the entire flash (usually 4 MB) over USB into a single .bin file. It lets you return to the pre-install state — with one command or the button below.

  • Czas: 4 MB przy 460800 b/s to około 1,5–2 min; przy 115200 b/s około 6–7 min.Time: 4 MB at 460800 baud takes about 1.5–2 min; at 115200 baud about 6–7 min.
  • Rozmiar flasha jest odczytywany z układu (ID kostki); 4 MB to tylko awaryjne założenie, gdy odczyt zawiedzie.The flash size is read from the chip itself (flash ID); 4 MB is only a fallback if that fails.
  • Tylko ESP32 (to, co siedzi na CYD). Płytka z S3/C3 zostanie rozpoznana i odrzucona.Only ESP32 (what the CYD carries). An S3/C3 board is detected and refused.
Kopia zawiera WSZYSTKO z flasha — także partycję NVS, a w niej hasła sieci WiFi zapisane przez obecny program. Plik trzymaj jak hasło. Nie odłączaj kabla w trakcie i nie zamykaj karty przeglądarki. The backup contains EVERYTHING in flash — including the NVS partition and, inside it, WiFi passwords saved by the current program. Treat the file like a password. Do not unplug the cable or close the browser tab while it runs.

Po naciśnięciu wybierz port z CH340 albo usbserial w nazwie. Płytka sama wchodzi w tryb programowania (przez DTR/RTS); gdy nie chce — trzymaj BOOT przy podłączaniu kabla. Gdy 460800 b/s zawodzi (zrywa się w trakcie, „Serial data stream stopped”), wybierz 115200 b/s.When asked, pick the port with CH340 or usbserial in its name. The board enters bootloader mode by itself (via DTR/RTS); if it refuses — hold BOOT while plugging the cable in. If 460800 fails (drops mid-way, “Serial data stream stopped”), choose 115200.

Potem, w 5 punktachAfterwards, in 5 points


    
  
  • Pierwszy start = kreator. K-OS prosi o kalibrację dotyku (4 rogi) i pokazuje menu. Autostart w tym biegu jest pomijany.First boot = wizard. K-OS asks for touch calibration (4 corners) and shows the menu. Autostart is skipped on that boot.
    • 
  
  • Karta microSD, FAT32 (karty powyżej 32 GB trzeba sformatować na FAT32 osobno). Programy trafiają do /programy/cyd24/ albo /programy/cyd28/ — jeden plik .bin to jedna aplikacja.microSD card, FAT32 (cards over 32 GB need a separate FAT32 format). Apps go to /programy/cyd24/ or /programy/cyd28/ — one .bin is one app.
    • 
  
  • Najprościej przez sklep: ustawienia → sieć WiFi → skanuj i połącz, potem w menu głównym sklep KORONA. Programy lecą z GitHuba wprost na kartę.Easiest via the store: settings → WiFi → scan and connect, then KORONA store in the main menu. Apps download from GitHub straight to the card.
    • 
  
  • Autostart 3 s. K-OS sam wchodzi w ostatni program; dotknij ekranu w czasie odliczania, żeby zostać w menu. Reset = powrót do menu.Autostart in 3 s. K-OS enters the last app by itself; tap the screen during the countdown to stay in the menu. Reset = back to the menu.
    • 
  
  • Każda aplikacja ma własne ustawienia — K-OS trzyma je na karcie osobno, więc się nie mieszają. Nazwa pliku jest kluczem tych ustawień; nazwę do wyświetlania K-OS trzyma oddzielnie.Each app keeps its own settings — K-OS stores them separately on the card, so they never mix. The file name is the key to those settings; the display name is kept separately.

  „Reset wraca do menu" dotyczy programów ze sklepu KORONA. Obcy plik .bin wrzucony na kartę nie zna tej umowy: po starcie płytka będzie w niego wracać po każdym resecie. Wyjście: podłącz USB i wgraj K-OS tą stroną jeszcze raz (tryb programowania: trzymaj BOOT przy podłączaniu). Nic nie ginie na stałe.
  “Reset returns to the menu” holds for apps from the KORONA store. A foreign .bin dropped on the card does not know that contract: once started, the board will keep returning to it after every reset. Way out: connect USB and install K-OS from this page again (bootloader mode: hold BOOT while plugging in). Nothing is lost for good.

  • Menu na ekranie płytki: wybierasz program z karty, K-OS kopiuje go do slotu roboczego i uruchamia.A menu on the board's screen: pick an app from the card, K-OS copies it to the working slot and runs it.
    •

  • Sklep przez WiFi, serwer www do zarządzania kartą z telefonu, osobne ustawienia dla każdej aplikacji.A WiFi store, a web server to manage the card from your phone, separate settings per app.

  • Ta strona wgrywa sam K-OS. Programy dokładasz potem z płytki.This page installs K-OS only. Apps come later, from the board itself.

  Co trafia do flashaWhat gets written to flash
  

    
Te same trzy pliki i to samo kasowanie wskaźnika rozruchu, co skrypt flash.sh z repozytorium. Układ: 4 MB, K-OS w partycji factory, uruchamiany program w slocie ota_0. Tablica partycji pod 0x8000 jest nadpisywana — dane innego firmware'u, które wcześniej tam było, przestają być czytelne.The same three files and the same boot-pointer clear as the repository's flash.sh. Layout: 4 MB, K-OS in the factory partition, the running app in the ota_0 slot. The partition table at 0x8000 is overwritten — data left by any previous firmware becomes unreadable.

    

      
      
offsetplikfileco to jestwhat it is

      
        
0x1000bootloader.binbootloader ESP32 (2. stopnia)ESP32 second-stage bootloader

        
0x8000partitions.bintablica partycji K-OSK-OS partition table

        
0x10000loader.binK-OS, partycja factory (1408 KB)K-OS, factory partition (1408 KB)

        
0xe000otadata-pusta.bin8192 bajtów 0xFF: pusty wskaźnik rozruchu = „startuj factory"; zapisywany ostatni8192 bytes of 0xFF: a blank boot pointer = “boot factory”; written last

  Gdy coś nie idzieWhen something goes wrong
  

    
    
      
  • Nie ma portu do wyboru — kabel tylko ładuje albo brak sterownika CH340. Najpierw inny kabel, potem sterownik.No port to pick — a charge-only cable or no CH340 driver. Try another cable first, then the driver.
    • 
      
  • Port jest, ale nie łączy — port trzyma inny program (monitor portu, Arduino IDE, PlatformIO). Zamknij je. Jeśli nadal nic: trzymaj BOOT podczas podłączania kabla — płytka wchodzi w tryb programowania.Port is there but won't connect — another program holds it (serial monitor, Arduino IDE, PlatformIO). Close them. Still nothing: hold BOOT while plugging the cable in — the board enters bootloader mode.
    • 
      
  • Wgrało się, ekran czarny — zła płytka: 2.4" i 2.8" mają podświetlenie na innym pinie. Wgraj obraz drugiej.Flashed, screen stays black — wrong board: 2.4" and 2.8" drive the backlight from different pins. Install the other image.
    • 
      
  • Dotyk nie trafia — ustawienia → dotyk → kalibracja. Na 2.8" kalibracja startowa jest zgadywana; jeśli nie da się trafić w menu, K-OS przyjmuje komendy po USB (115200 b/s), np. RUN:<nazwa>.Touch is off — settings → touch → calibration. On the 2.8" the initial calibration is a guess; if the menu is unreachable, K-OS accepts USB commands (115200 baud), e.g. RUN:<name>.
    • 
      
  • Płytka wraca do obcego programu — patrz ramka wyżej: USB, BOOT, ta strona.The board keeps returning to a foreign app — see the box above: USB, BOOT, this page.
    • 
      
  • Da się cofnąć. Tryb programowania ESP32 siedzi w ROM-ie, więc żadne wgranie nie psuje płytki na stałe. Wyjątek: płytki z włączonym flash encryption lub secure boot — tam ta strona nie ma zastosowania.It can be undone. The ESP32 bootloader mode lives in ROM, so no flash ever bricks the board. Exception: boards with flash encryption or secure boot enabled — this page does not apply to them.
