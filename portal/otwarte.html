K-OS — strefa otwartaK-OS — open zone

Programy na płytki CYD dodane przez kogokolwiek, bez sprawdzania i bez akceptacji. Każdy może dodać swój, każdy może go zainstalować. Programy z kodem źródłowym mają znaczek „otwarte źródło”. Programs for CYD boards added by anyone, unchecked and unapproved. Anyone can add one, anyone can install it. Programs with source code get the "open source" badge.

⚠ UWAGA: NIKT TEGO NIE SPRAWDZIŁ⚠ WARNING: NOBODY HAS CHECKED THIS

Program ze strefy otwartej może zrobić na płytce wszystko: odczytać hasła WiFi z karty SD i z pamięci płytki i wysłać je w świat, udawać klawiaturę po Bluetooth i wpisywać polecenia na Twoim komputerze, atakować sieci wokół, skasować K-OS (wtedy pomoże tylko USB i portal).

A program from the open zone can do anything on the board: read WiFi passwords from the SD card and the board's memory and send them out, pretend to be a keyboard over Bluetooth and type commands on your computer, attack networks around you, erase K-OS (then only USB and the portal help).

Instalujesz na własne ryzyko. Wybieraj programy z otwartym źródłem i znanych autorów. Nie trzymaj na tej karcie haseł, których nie chcesz stracić.

You install at your own risk. Prefer open-source programs and authors you know. Do not keep passwords you care about on that card.

Płytka gwarantuje tylko jedno: zainstaluje dokładnie ten plik, który został zgłoszony (sprawdza sumę sha256 z podpisanego katalogu). To nie mówi nic o tym, co ten plik robi.

The board guarantees one thing only: it installs exactly the file that was submitted (it checks the sha256 from the signed catalog). That says nothing about what the file does.

Jak zainstalować na płytceHow to install on a board

Na płytce z K-OS (od wersji ze strefą): sklep → strefa otwarta → wybierz program → przeczytaj ostrzeżenie → przytrzymaj „rozumiem, instaluj”. Albo na stronie WWW płytki (adres IP z ekranu): karta strefa otwarta → zainstaluj → potwierdź palcem na płytce. Ta strona niczego do płytki nie wysyła.

On a board running K-OS (a version with the zone): store → open zone → pick a program → read the warning → hold "I understand, install". Or on the board's web page (IP address from the screen): the open zone tab → install → confirm with a finger on the board. This page sends nothing to the board.

Dodaj swój programAdd your program

Wrzuć plik .bin tam, gdzie chcesz (Google Drive z udostępnieniem „każdy z linkiem”, Dropbox, GitHub — najlepiej wydanie albo plik w repo), i wklej link. Serwer pobierze plik raz, sprawdzi, czy to obraz ESP32 mieszczący się w slocie (≤ 2 555 904 B), policzy sumę sha256 i zapisze wpis. Pliku nie przechowujemy — płytki pobierają go z Twojego linku. Jeśli później podmienisz plik pod tym linkiem, płytki go odrzucą: zgłoś wtedy nową wersję.

Put your .bin wherever you like (Google Drive shared as "anyone with the link", Dropbox, GitHub — ideally a release or a file in a repo) and paste the link. The server downloads the file once, checks it is an ESP32 image that fits the slot (≤ 2,555,904 B), computes the sha256 and saves the entry. We do not store the file — boards download it from your link. If you later replace the file behind that link, boards will reject it: submit a new version instead.

Podaj kod źródłowy. Strefa ma być otwarta: z linkiem do źródła (GitHub, GitLab…) i licencją z listy wpis dostaje zielony znaczek „otwarte źródło”, a ludzie mogą sprawdzić, co program robi. Bez źródła wpis ma czerwone ostrzeżenie „bez źródła”. Program pod GPL musisz udostępnić ze źródłem.

Give the source code. The zone is meant to be open: with a source link (GitHub, GitLab…) and a licence from the list your entry gets the green "open source" badge, and people can check what the program does. Without source the entry carries a red "no source" warning. A GPL program must be shared with its source.

Regulamin strefyZone rules

  1. Strefa otwarta to spis linków do programów dodanych przez użytkowników. Nikt ich nie sprawdza. Instalujesz na własne ryzyko.
  2. Dodając wpis, oświadczasz, że masz prawo udostępnić program i że nie jest złośliwy: nie wykrada danych, nie ukrywa swojego działania, nie atakuje cudzych sieci ani urządzeń.
  3. Zakazane: cudze oprogramowanie bez zgody autora albo wbrew jego licencji (także firmware innych producentów), treści naruszające prawo. Kod na licencji GPL udostępniaj ze źródłem.
  4. Za wpis i plik odpowiada jego autor. Piotr Korona prowadzi spis i może usunąć każdy wpis po zgłoszeniu albo z własnej decyzji; usunięty plik nie wróci pod innym linkiem.
  5. Naruszenie zgłoś przyciskiem zgłoś przy wpisie (możesz podać kontakt, np. jako właściciel praw). Wpis zgłoszony przez 3 różne osoby jest ukrywany do decyzji Piotra. Zgłoszenia są rozpatrywane bez zbędnej zwłoki.
  6. Strefa działa bez żadnej gwarancji i może zostać zmieniona albo wyłączona.
  1. The open zone is a list of links to programs added by users. Nobody checks them. You install at your own risk.
  2. By adding an entry you declare that you have the right to share the program and that it is not malicious: it does not steal data, hide what it does, or attack other people's networks or devices.
  3. Forbidden: other people's software without the author's consent or against its licence (including other vendors' firmware), unlawful content. Share GPL code with its source.
  4. The entry's author is responsible for the entry and the file. Piotr Korona keeps the list and may remove any entry after a report or at his own discretion; a removed file cannot come back under another link.
  5. Report a violation with the report button on the entry (you may leave a contact, e.g. as the rights holder). An entry reported by 3 different people is hidden until Piotr decides. Reports are handled without undue delay.
  6. The zone comes with no warranty whatsoever and may be changed or shut down.

PrywatnośćPrivacy

Zapisujemy to, co wpisujesz w formularzu (pseudonim, opisy, linki, licencję; w zgłoszeniu: powód, opis i opcjonalny kontakt), a także rozmiar i sumę pliku oraz datę. Adresu IP nie zapisujemy — do limitów i liczenia „różnych osób” służy jego skrót (HMAC z tajną solą), kasowany po 2 dobach, a przy zgłoszeniach po 90 dniach. Bez ciasteczek i analityki; ta strona pamięta w przeglądarce tylko wybrany język. Plik pobieramy raz, do sprawdzenia, i go nie przechowujemy. Serwer działa na Cloudflare, który technicznie przetwarza adres połączenia według własnej polityki. Usunięcie danych: wycofaj wpis kluczem autora albo zgłoś wpis z prośbą o usunięcie.

We store what you type into the form (nickname, descriptions, links, licence; in a report: reason, text and an optional contact), plus the file size, hash and date. We do not store IP addresses — limits and counting "different people" use a hash of it (HMAC with a secret salt), deleted after 2 days, and after 90 days for reports. No cookies, no analytics; this page only remembers the chosen language in your browser. We download the file once to check it and do not keep it. The server runs on Cloudflare, which technically processes the connection address under its own policy. To remove data: withdraw the entry with your author key, or report the entry asking for removal.
